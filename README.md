# dYnex? — Official Interactive 3D Music Archive

> Официальный интерактивный 3D музыкальный архив и цифровое пространство артиста **dYnex?** (2023—2026).
> 
> Построен на **Three.js**, **React Three Fiber**, **Tailwind CSS**, **Framer Motion** и **TypeScript**.

---

## 🌌 Концепция и Архитектура

В отличие от стандартных музыкальных сайтов, 3D пространство здесь — это **не фон**, а **само интерактивное измерение сайта**:
1. **Глубокое 3D звёздное поле (Starfield)**:
   - 4 независимых уровня глубины (`DEEP`, `MID`, `NEAR`, `FOREGROUND`) на GPU-системе частиц (`THREE.Points`).
   - При скролле камера физически перемещается по оси $Z$ от $0$ до $-5800$, открывая новые звёзды и оставляя пройденные позади.
   - Скорость скролла динамически растягивает ближние частицы, создавая кинематографичный космический шлейф.
2. **Физические 3D объекты релизов**:
   - Каждый релиз представляет собой трёхмерный объект с настоящей обложкой высокого разрешения (1000×1000), матовыми тёмными гранями и сигнальной красной подсветкой.
   - В зоне архива релизы образуют интерактивную 3D орбиту с поддержкой перетаскивания (drag/touch) и физической инерции.
3. **Кинематографичный переход**:
   - Клик по релизу останавливает орбиту, вытягивает объект вперёд к камере и открывает подробный терминал с предпрослушиванием аудио и ссылками на Apple Music, Spotify, VK Музыку и YouTube.
4. **Сеть коллабораций (3D Network)**:
   - Трёхмерный граф взаимосвязей артиста `dYnex?` с подтверждёнными продюсерами (VERV!X, gveor, TRVNSPORTER, ZomboBox!, Sx1nxwy и др.).
5. **Система управления `/admin`**:
   - Полноценная административная панель для добавления, редактирования, скрытия, переупорядочивания и назначения главного релиза.
   - Мгновенная синхронизация с 3D миром и сохранение в `localStorage`.
   - Импорт и экспорт каталога в JSON.

## 🎨 Цветовая палитра и стиль

- **Глубокий космос / Бездна:** `#020204`, `#050507`, `#08090C`, `#111216`
- **Технический монохром:** `#F2F2EE`, `#D8D8D5`, `#77777D`
- **Сигнальный акцент:** Сигнальный глубокий красный `#E61924` (вопросительный знак `dYnex?`, активные маркеры, подсветка)
- **Строгое правило:** Никакого фиолетового, кислотных градиентов и назойливого шума.

## 🚀 Запуск и Разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера с HMR
npm run dev

# Сборка для production (Vercel)
npm run build

# Предпросмотр сборки
npm run preview
```

Готово к развертыванию на **Vercel** (`vercel.json` включен в корень репозитория).
